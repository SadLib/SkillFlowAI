# Pitch Shark Tank IA · máximo 8 minutos

**Petición para el panel.** Buscamos el apoyo de un retailer para validar un piloto de cuatro semanas en dos sucursales. Antes de negociar una inversión, queremos comprobar si el equipo consulta y aplica sus procedimientos con mayor rapidez y precisión.

| Tiempo | Responsable sugerido | Contenido |
|---|---|---|
| 0:00–0:55 | Producto | Abre con el caso de Valeria y Diego. Dos equipos tienen bandejas de solicitudes pendientes y necesitan encontrar una forma de organizarlas. |
| 0:55–1:40 | Producto | Presenta el coach por texto y muestra cómo una práctica de un empleado puede convertirse en una guía compartida. |
| 1:40–2:15 | Negocio | Define al comprador inicial como responsable de capacitación u operaciones en retail. Explica la hipótesis de piloto pagado y suscripción por empleado activo. |
| 2:15–4:55 | Demo | Ejecuta los 2 min 40 s del guion, desde la sesión 1 a 1 de Valeria hasta el registro de la aplicación de Diego. |
| 4:55–6:05 | IA | Explica TF-IDF, regresión logística, recuperación por coseno y reglas. Muestra 36/40 aciertos y la matriz del laboratorio. Identifica los datos como académicos. |
| 6:05–7:10 | Ingeniería | Describe qué construiría el equipo para un piloto, incluyendo permisos, versionado de documentos y almacenamiento. Propón medir tiempo de búsqueda, aplicación correcta de la política y finalización de guías. |
| 7:10–8:00 | Negocio | Repite la petición de dos sucursales. Cierra con una pregunta para el panel: «¿Qué proceso operativo pondrían a prueba primero?» |

## Hechos para presentar

- El MVP ejecuta clasificación, recuperación, respuesta con fuente, evaluación y recomendación. Las sesiones 1 a 1 permiten documentar un ejemplo, publicar una guía y registrar su aplicación por otro empleado.
- El clasificador obtuvo 36 aciertos en 40 ejemplos de prueba escritos para este proyecto.
- La recuperación encontró el documento esperado primero en 9 de 9 consultas de referencia y se abstuvo en dos consultas ajenas al catálogo.
- NovaRetail es una empresa ficticia. El equipo y su actividad inicial son ilustrativos.

## Hipótesis para validar

- El área de capacitación asumiría la compra y operaciones participaría en la elección de procedimientos.
- Un piloto pagado podría convertirse en una suscripción mensual por empleado activo.
- La consulta con fuentes podría reducir el tiempo de búsqueda y mejorar la aplicación de políticas. El piloto necesita una línea base y casos comparables antes de sostener esa afirmación.
- Los procedimientos de devoluciones y entregas pueden ser un punto de partida para un catálogo limitado y verificable.

Para medir el piloto, acuerda una línea base de consultas operativas con el equipo y usa casos equivalentes antes y después. El tiempo y la respuesta correcta se miden por separado. Registra también cuántas veces el sistema se abstiene y cuántas consultas necesitan intervención de un supervisor.
